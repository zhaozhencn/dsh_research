# 源码技术文章深化

## 范围与原则

将源码证据组织为连贯文章，同时保留用户要求的关注点、主体结构和有效原文摘录。支持单篇深化、样篇带动系列和已核实版本的文章同步。默认由单一执行者完成研究、编辑与复核，无须用户逐步介入；提交、推送和外部发布不随文章编辑自动授权。

先读取工作区规则和当前文章。固定源码完整SHA，区分源码事实、官方说明、运行验证、推断与改造建议。使用本地提交对象查证代码；缺少依据时查官方源码和文档，不能凭术语猜实现。新旧版本的机制调查交给对应研究流程；对DeepSeek Harness可配合 `harness-research-sync`，前提是该技能可用。

## 执行顺序

1. **明确范围并保存原状。** 列出目标文章、读者、中心问题、源码基线和需保护的其他文章／资产。记录标题、步骤、代码与图片；同SHA深化默认保留有效摘录。跨版本时保留历史证据，允许依据新源码替换正文代码并记录原因。
2. **先输出结构化梳理。** 使用 [article-plan.json](assets/article-plan.json) 保存工作计划，按 [workflow.md](references/workflow.md) 建立调用／事件／数据关系、关键结构与篇章安排。阶段成果可以写入工作文件并简要汇报，不等待审批。
3. **写整体说明。** 开篇交代关注点为什么重要、入口是什么、主线经过哪些职责、读者将理解什么；整体图配合这段说明。避免一上来就截取函数内部。
4. **沿交接对象深入代码。** 每一步从真实caller进入callee，解释关键条件、await和状态变化，指出返回值或事件由谁消费，再连接下一步。装配、执行、恢复和卸载分别交代生命周期；不要以连续连接词替代真实因果关系。
5. **解释关键数据。** 在首次关键消费前展示准确声明，说明字段、身份、生产者、consumer、状态转移、提交点与释放责任。区分公开字段、继承、局部变量和闭包，不新增不存在的字段来简化图示。
6. **组织配图。** 按 [illustrations.md](references/illustrations.md) 选择图型与位置，正文和图中保留Agent、Turn、Step等原语及真实标识。长专栏可采用四图组织，但数量服从用户要求与文章长度。技术图优先使用可编辑定义和确定性渲染；查看实际输出。
7. **写工程心得。** 正文解释收益、代价与适用条件；结尾从具体实现推导可操作做法，回应中心问题。避免重新堆叠不足、泛谈“解耦／可扩展”，或将企业建议写成项目已有保证。
8. **复核后交付。** 按 [validation-and-sync.md](references/validation-and-sync.md) 检查证据、结构、图文与保护范围。系列逐篇完成语义复核，更新目录和当前清单，保留历史日志。交付说明修改范围、实测结果与未验证范围。

## 按需使用辅助脚本

`scripts/evidence_tools.py` 仅使用Python标准库，读取本地Git和文件，不联网、不修改文章。用绝对路径调用，或先进入本技能目录。

```sh
# 从固定提交提取原文；stdout含完整SHA、行范围及选段hash
python3 scripts/evidence_tools.py extract --repo /path/to/source --rev FULL_SHA --path src/file.ts --start 10 --end 28
# 保存修改前的基线；输出文件必须尚不存在
python3 scripts/evidence_tools.py snapshot --root /path/to/docs --files articles/topic.md --protect articles/reference.md --out /path/to/work/before.json
# 比较当前文章；仅在用户要求时指定图片数量
python3 scripts/evidence_tools.py compare --root /path/to/docs --baseline /path/to/work/before.json --images 4
```

默认保留二级标题、编号步骤和既有代码块。经任务授权调整标题措辞可用 `--headings same-count`，并记录主题对应；新版本替换代码可用 `--code-policy any`，并重新核对全部当前源码。脚本不能判断调用链真实、文章流畅或图示正确，不把通过结果称为语义质量认证。更复杂的链接、图序和源码清单检查优先复用项目现有工具。

## 完成标准

- 开篇提供整体机制；所有函数切换有可追溯的关系，代码解释能回到文章中心问题。
- 关键结构和状态由源码支持，正常与异常路径说明清楚，推断与建议有标记。
- 配图分散在需要它的段落，术语、边、字段、条件及图注与正文一致。
- 原有主体关注领域得到保留，未选中文件保持原状，系列目录和当前记录同步。
- 结尾至少给出与正文对应的具体工程收获，不以篇幅、图数或代码块数替代深度。
- 实际检查的命令、退出码与限制可追溯；同SHA编辑不会被说成重跑了历史行为测试。
